# Content guidelines

Thapar Talks is centered only on Thapar Institute of Engineering and Technology (TIET), Patiala.

## Source basis

Society and event names used in the demo are based on TIET's public student-society directory and event calendar:

- https://www.thapar.edu/students/pages/student-societies
- https://www.thapar.edu/events

The demo features TIET names such as FAPS, MUDRA, Creative Computing Society, PWS, Pratigya, URJA, Saturnalia, Izhaar, Frosh Week, MUDRA Eve, ELIXIR, the Thapar Food Festival, and the Annual Athletic Meet.

## Mock-data boundary

- Student names, usernames, conversations, captions, follower counts, post counts, and engagement numbers are fictional demo data.
- Society and event names should come from a public TIET source before being added.
- Do not imply that mock handles are official social-media accounts.
- Do not invent dates, venues, organizers, sponsors, or results for real TIET events.
- Keep bundled demo media local so the presentation works without a network connection.

## Media policy

- Store raster UI assets as WebP in `web/public/images`.
- Run `npm run images:webp` from `web` when source JPG, JPEG, or PNG assets need conversion.
- Videos may remain MP4.
