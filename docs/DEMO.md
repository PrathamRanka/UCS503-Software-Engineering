# Demo Guide

## Before presenting

```bash
cd web
npm install
npm run dev
```

Open the URL shown by Vite. The photos are stored locally, so the demo feed does not depend on an internet connection.

## Suggested 60-second walkthrough

1. Select **Continue with Google**, then choose the verified `@thapar.edu` account.
2. Show the responsive home feed and story row.
3. Toggle dark mode, refresh once to show persistence, then return to the light-first demo theme.
4. Open a story and use the arrow keys to move between stories.
5. Double-click a post image to like it, then save, comment and share.
6. Open Search, Explore, Reels, Messages and Notifications from the sidebar.
7. Point out the TIET society and event content in Explore.
8. Select **Create**, choose **Use demo photo**, write a caption and share it.
9. Open Profile to show posts, saved content, highlights and settings.
10. Open a feed post to show its routed detail/comments screen and content menu.
11. Create a Story and Reel; play the local Reel video.
12. Start a direct or group conversation and send an image.
13. Resize to mobile width and show the bottom navigation.

## Demo limitations

- Feed interactions reset when the page refreshes.
- The mock authentication session and profile settings persist locally.
- Real authentication, APIs, uploads and database persistence belong to the backend phase.
- Society and event names are TIET-based; student identities and engagement data are fictional.
- All bundled raster images are WebP, and the local reel remains MP4.
