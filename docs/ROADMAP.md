# Roadmap

## Phase 1: Frontend demo — complete

- Responsive campus feed
- Stories preview
- Post interactions
- Post composer
- Campus trends and suggestions
- Component-based React structure

## Phase 2: Small backend

- Create Node.js and Express API
- Add health endpoint
- Add PostgreSQL connection
- Add users and posts endpoints
- Replace mock feed data with API responses

## Phase 3: Core social features

- Authentication
- User profiles
- Image upload
- Comments
- Follow relationships
- Basic communities

## Phase 4: Polish

- Loading, empty, and error states
- Form validation
- Accessibility review
- Unit and browser tests
- Simple deployment

## Optional future work

- Messaging
- Notifications
- Story creation
- Video posts
- Administration tools

Optional work should begin only after the core product is complete.
