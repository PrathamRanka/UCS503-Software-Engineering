# User Flows

## Demo flow

1. Open the home feed.
2. Browse stories and campus posts.
3. Like, save, or share a post.
4. Follow suggested students or clubs.
5. Open the post composer and share a mock post.
6. Switch to the mobile layout to demonstrate responsive navigation.

## MVP sign-in flow

```text
Open application → Sign in → Complete profile → View home feed
```

## MVP posting flow

```text
Create post → Select image → Write caption → Publish → Post appears in feed
```

## MVP social flow

```text
Open profile → Follow user → See their posts in following feed
```

## Later flows

Communities, direct messages, notifications, stories upload, and moderation can be added after the core feed and profile flows are stable.
